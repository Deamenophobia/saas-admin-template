# Changelog

## 0.3.1 — 2026-10-29

- Prepare the MIT-licensed developer preview and retain original source attribution.
- Update Nodemailer, Resend, Zod and affected transitive dependencies to address
  dependency advisories identified during publication preparation.
- Keep npm publication disabled; this project is intended to be used as a source template.

## 0.3.0 — 2026-10-29

- Add optional OIDC client sign-in with PKCE, signed-token validation, one-use bound
  flows, explicit linking, local MFA and identity-specific session revocation.
- Add provider setup documentation and a browser callback helper.

## 0.2.0 — 2026-10-29

- Add product permissions/routes, lifecycle hooks, tenant suspension, entitlement
  interfaces, versioned durable events and an operator-invoked dispatcher.
- Add team-project and API-service examples with documented API responses.

## 0.1.0 — 2026-10-29

- Extract auth, organizations, memberships, administration, service accounts, scoped
  API keys, audit logging and optional credential provisioning from the original repos.
